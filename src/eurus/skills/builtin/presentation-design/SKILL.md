# Presentation Design Skill

Use when building a PowerPoint deck. The Eurus Office Department plans each slide with a layout
engine; this skill guides the Production Agent's layout choices and the Design Agent's direction.

## Narrative

- Start with the audience, decision, and desired outcome.
- Give each slide one central point expressed as a claim-style title, not a generic topic label.
- Sequence slides as context, insight, evidence, implication, and next action when that narrative
  fits the brief.
- Separate sourced facts, estimates, assumptions, and recommendations. Never invent statistics,
  customer quotes, or citations.
- Prefer concise wording and useful specifics over vague business language.

## Layout system

The engine composes these layouts; pick the one that fits the content, and vary composition:

- `cover` for the title slide, `agenda` for the roadmap, `section_divider` between chapters.
- `content` for bullets with an optional callout bar, `two_column` or `comparison` for contrast.
- `timeline` for chronology, `process` for staged flows, `metrics` for KPI cards.
- `chart` for native column, bar, line, or pie charts with a takeaway bullet list.
- `quote` for a single memorable statement, `case_study` for evidence plus a metric.
- `conclusion` for takeaways and next steps, `references` for sources.
- `image_lead` pairs a picture with supporting bullets when an image file is actually available.

Design directions: editorial, corporate, minimal, educational, scientific, technical, historical,
data-driven, modern keynote. Choose based on content and audience; never force one theme onto
every deck. Do not use the same layout for more than three consecutive slides.

## Visual system

- Use a restrained palette, consistent typography, and generous whitespace; the direction tokens
  handle palette and fonts, so keep text within the planned regions.
- Use charts for quantitative comparisons, tables for exact values, diagrams for systems, and
  timelines for sequence. Avoid paragraphs on slides; move supporting detail to speaker notes.
- Use callouts sparingly for decisions, risks, or memorable findings.
- Keep titles, body text, alignment, spacing, and slide numbers consistent.

## Final quality gate

Before delivery, check narrative continuity, factual support, slide-to-slide repetition,
typography hierarchy, contrast, density, and whether the deck answers the original brief. The
department renders every deck through LibreOffice and inspects the pages: overflow, clipping,
overlap, empty slides, and out-of-bounds shapes are rejected automatically.
